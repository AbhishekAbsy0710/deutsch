# Global Agent Behavior

## Obsidian Memory Check (MANDATORY)

Before answering any non-trivial question, ALWAYS search Obsidian for relevant past context using the CLI:

```bash
~/bin/obsidian search query="<relevant keywords>" limit=5
```

This is especially critical for:
- Questions about past decisions, implementations, or debugging sessions
- Questions where the user says "remember", "last time", "before", "previous"
- Any work on Ayonic, Kyaani, or other known projects
- Deployment, payment, or architecture questions that may have established patterns

If relevant Obsidian notes are found, read them with:
```bash
~/bin/obsidian read file="<note name>"
```

Use this context to ground your answers in what was actually discussed and decided previously. This prevents contradicting past work or repeating solved problems.

**The Obsidian vault at `~/Documents/Obsidian Vault/Antigravity/` contains all past Antigravity conversations, artifacts, and knowledge items.** Treat it as your long-term memory.
